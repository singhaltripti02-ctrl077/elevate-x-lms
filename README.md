Elevate X – Digital Capacity Building Platform

About the Project

Elevate X is a prototype of a Learning Management System (LMS) designed to support digital learning and capacity building. It provides separate dashboards for Admin, Trainers and Trainees.

Key Features

- Admin: Manages and oversees the platform.
- Trainer: Accesses course-related features and assessments.
- Trainee: Views courses and participates in quizzes.
- Login system with role-based dashboards.
- Course and competency management.
- Quiz and assessment functionality.
- Custom platform logo and user interface.

Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

Project Structure

- "app.py" – Main Flask application.
- "requirements.txt" – Required Python libraries.
- "static/" – Contains the project logo.

How to Run Locally

1. Install Python.
2. Install dependencies:
   "pip install -r requirements.txt"
3. Run the application:
   "python app.py"
4. Open "http://127.0.0.1:5000" in your browser.

Note

This project is developed as an academic prototype. It uses temporary in-memory data and is intended for demonstration purposes.
